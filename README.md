# Food Munch

A responsive static food website clone built with **HTML** and **CSS**, focused on a clean layout and a mobile-friendly design.

![Food Munch Preview](assets/Food-Munch_image.png)

## Live Demo

[View the live site](REPLACE_WITH_LIVE_LINK)

## Features

- Clean, easy-to-read layout
- Fully responsive: works on mobile, tablet and desktop
- Built with plain HTML and CSS, with no frameworks or libraries
- Consistent styling for sections, buttons and cards

## Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| HTML5 | Page structure and content |
| CSS3 | Styling, layout and responsive design |

## Project Structure

```
food-munch-html-css/
├── index.html
├── style.css
├── assets/        (images used in the website)
└── README.md
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/ShaikAsifa2612/food-munch-html-css.git
   ```

2. Open the project folder:

   ```bash
   cd food-munch-html-css
   ```

3. Open `index.html` in your browser. No installation or build step is needed.
